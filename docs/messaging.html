How agents ask each other

You and agent1 are talking in thread 1. You say "ask agent2 what time it is". Step through what lands where, with the arrow keys.

Solid columns are threads: a group chat everyone reads, which never talks to a model. Dashed columns are each agent's own conversation, exactly the turns its model provider sees. Providers only take system, user, assistant and tool result, so everyone else in the thread, humans and agents, reaches an agent as a user turn with a name in front. Its assistant turns are only ever its own words and tool calls.

The types, from server.js 
/** @typedef {{ runner: string, model: string, thinkingLevel?: string, dir?: string }} To   An agent, model@runner.
 *  @typedef {object} Message   The data of every thread entry.
 *  @property {string} author   A human's name, or an agent's.
 *  @property {string} body
 *  @property {To[]} [to]       The agents it asks.
 *  @property {number} [from]   The thread it came from.
 *  @property {number[]} [re]   What it answers: messages here, or with `from`, posts there.
 *  @property {{ conversation: number, entry: number }} [answer]   The agent's entry it copies.
 *  @typedef {{ id: number, kind: 'agent-ide.message', data: Message }} Entry
 *  @typedef {{ agent: number, held: number[], steer: boolean }} Delivery   What one input to an agent holds.
 */
Thread    doc on a thread:       { title, parent, createdAt, hidden, reads, agents: { name → conversation id } }
AgentHome doc on an agent's own: { thread, name, unseen: entryId[] }   the thread messages it hasn't seen

post tool (talk.js): { thread?: number, title?: string, body: string, to?: 'model@runner' | runner | 'nobody' }
  no thread → a new child thread of yours; your own thread → refused ("That is your own thread; just answer")

Hello, Agent IDE

npx github:oskarrough/agent-ide

Lend it your laptop

Now an agent can work on the server's own machine. To have it work on your laptop instead, run this there. Your laptop dials the server, so it has to reach it: the same network, or Tailscale.


  


  

    
Watch its hands

    
The thinking happens on the server. Every tool call travels down the wire and runs on the runner, in its folder.

    

  


  

    
Bring a friend

    
A thread isn't yours alone. Send someone the link and they're in it, writing next to you and your agents.

    

    
There are no accounts: a name is whatever you say it is. Keep the server on a network you trust.

  


  

    
Ask two at once

    
Click a runner to ask it. Shift-click another to ask it too. One message, two agents, each answering from its own machine.

    

  


  

    
Agents talk to each other

    
An agent can start a thread of its own and ask someone else. The answer comes back to it once, and only then does it answer you.

    

  


  

    
Pull the plug

    
Ask something slow, and while the wire is green, stop the server: Ctrl-C where it runs. Start it again. The answer lands, once.

    
Nothing here keeps state. Close this tab, or the laptop, and nothing is lost either.

  


  

    
Fork

    
Wish you'd asked differently? Every message has a fork. A new thread starts from there, with the same agents, who remember only what came before it.

  


  

    
Memory

    
Placeholder. A thread that never has to end, and anything said in it found again word for word. Still being explored, behind MEMORY=1.

Lend it your laptop

Now an agent can work on the server's own machine. To have it work on your laptop instead, run this there. Your laptop dials the server, so it has to reach it: the same network, or Tailscale.


  


  

    
Where the work happens

    
The thinking happens on the server, the work on the runner. Each tool the agent calls travels down its wire and runs in the runner's folder, with the runner's logins. While it works, the line under the agent shows what its hands are doing.

    

  


  

    
Bring a friend

    
A thread isn't yours alone. Send someone the link and they're in it, writing next to you and your agents.

    

    
There are no accounts: a name is whatever you say it is. Keep the server on a network you trust.

  


  

    
Ask two at once

    
Click a runner to ask it. Shift-click another to ask it too. One message, two agents, each answering from its own machine.

    

  


  

    
Agents talk to each other

    
An agent asks another with its post tool. With no thread, it starts a child that holds just the question. Given a thread, it asks whoever is there, with everything they already know there.

    
The answer comes back once, as a card, and wakes whoever asked. Nothing else crosses: what's said in a child stays in the child. And an agent's words reach others marked as an agent's, so none can pass for yours.

    

  


  

    
Pull the plug

    
Ask something slow. While its wire is green, stop the server where it runs, with Ctrl-C, and start it again. The server goes dashed, then green, and the answer lands, once. A command that was running when the plug came out is cut off, and the agent says so: it picks up where Pi left it, not where the shell was.

    

    
This page keeps nothing itself. Close the tab, or the laptop, and nothing is lost either.

  


  

    
Fork

    
Wish you'd asked differently? Hover any message for its fork. A new thread starts from there, with the same agents, each remembering only what came before it. The two sit side by side, linked both ways.

    

  


  

    
Memory

    
A thread that never has to end. Each message gets one short line, pairs of lines merge into one going up, and an agent reads those lines instead of every word. When it needs the words, it zooms back down. Click a line to do the same.

    
Load a thread of three people building a shed: 32 messages, where the gate code and the colour change halfway. Watch the lines get written, from the messages up. Then ask an agent what's true now.
